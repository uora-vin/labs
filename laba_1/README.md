# Лабораторная работа № 1 — объектно-ориентированная модель ресторана

## О работе

Учебный проект на Python, моделирующий предметную область ресторана
с использованием объектно-ориентированного программирования. Программа
предназначена для демонстрации классов и связей между сущностями, базовых
операций управления данными (CRUD), обработки исключений и сериализации
в форматах JSON и XML.

Вариант 25 — «Ресторан».

## Основные возможности

- представление сущностей предметной области ресторана с помощью классов;
- операции добавления, поиска, изменения и удаления записей (CRUD);
- проверка входных данных и обработка ошибок (встроенные и собственные
  исключения `RestaurantError`, `InsufficientFundsError`, `EmptyOrderError`);
- оплата заказа с баланса гостя: списание, проверка нехватки денег
  и пустого заказа;
- сохранение и загрузка данных в форматах JSON и XML;
- демонстрационный набор данных;
- консольное меню для работы с данными;
- UML-диаграмма классов в графическом и редактируемом форматах.

Все данные в демонстрационном наборе вымышлены. Проект не предназначен
для хранения реальных персональных данных и не является информационной
системой предприятия общественного питания.

## Требования

- Python 3.10 или новее;
- внешние библиотеки не требуются (используется только стандартная
  библиотека).

## Запуск

Перейдите в каталог `restaurant_new` и выполните:

```bash
python cli.py
```

Для создания демонстрационных файлов JSON/XML в каталоге данных:

```bash
python cli.py --demo
```

При необходимости можно указать другой каталог данных:

```bash
python cli.py --demo --data ./data
```

В PyCharm достаточно открыть `cli.py` и нажать **Run** (Shift+F10).

## Классы

- `Person` — базовый класс человека (`id`, `full_name`, `phone`);
- `Employee(Person)` — сотрудник (`position`, `salary`);
- `Customer(Person)` — гость (`discount_percent`, `balance`, метод `pay()`);
- `Category` — категория меню;
- `Ingredient` — ингредиент (`name`, `unit`);
- `MenuItem` — позиция меню (`category_id`, `price`, `weight`);
- `RecipeLine` — строка рецепта (`menu_item_id`, `ingredient_id`, `amount`);
- `Table` — столик (`seats`, `zone`);
- `Reservation` — бронирование столика;
- `Order` — заказ (`customer_id`, `employee_id`, `table_id`, `status`,
  метод `pay()`);
- `OrderItem` — позиция заказа (`menu_item_id`, `quantity`);
- `Restaurant` — хранилище данных и операции CRUD;
- `RestaurantError`, `InsufficientFundsError`, `EmptyOrderError` —
  собственные исключения.

## Исключения

| Исключение | Когда возникает |
|---|---|
| `RestaurantError` | пустые поля, неверные числа и даты, неизвестные ID, повторная оплата, удаление связанных записей |
| `InsufficientFundsError` | на балансе гостя не хватает денег на оплату заказа |
| `EmptyOrderError` | попытка оплатить заказ без блюд |

`InsufficientFundsError` и `EmptyOrderError` наследуются от
`RestaurantError`, поэтому в меню достаточно одного обработчика:

```python
try:
    restaurant.pay_order(order.id)
except RestaurantError as exc:
    print(f"Ошибка: {exc}")
```

## Форматы данных

Программа поддерживает сохранение и загрузку JSON и XML. Это позволяет
представить одну и ту же модель данных в двух форматах и продемонстрировать
сериализацию и десериализацию.

Структура JSON:

```json
{
  "restaurant": "Ресторан «Тёплый вечер»",
  "categories": [{"id": 1, "name": "Салаты", "description": "Холодные закуски"}],
  "menu_items": [{"id": 1, "name": "Салат «Цезарь»", "category_id": 1,
                  "price": 520.0, "weight": 260.0, "description": "..."}],
  "customers": [{"id": 1, "full_name": "Алексей Петров",
                 "phone": "+7-900-444-55-66",
                 "discount_percent": 0.0, "balance": 5000.0}],
  "orders": [{"id": 1, "customer_id": 1, "employee_id": 1,
              "created_at": "2026-11-20 18:30", "table_id": 2, "status": "Новый"}]
}
```

Структура XML повторяет JSON: 

```xml
<restaurant name="Ресторан «Тёплый вечер»">
  <customers>
    <customer>
      <id>1</id>
      <full_name>Алексей Петров</full_name>
      <phone>+7-900-444-55-66</phone>
      <discount_percent>0.0</discount_percent>
      <balance>5000.0</balance>
    </customer>
  </customers>
</restaurant>
```

Подробное описание всех сущностей и полей — в `data/restaurant_data.txt`.
