# Лабораторная работа № 2 — регулярные выражения и unit-тестирование

**Вариант 25:** проверка и поиск синтаксически корректных паспортных данных.

## О работе

Программа на Python проверяет, соответствует ли строка паспортным данным, и находит такие данные в произвольном тексте, локальном файле или тексте загруженной веб-страницы. Для проверки используется регулярное выражение, а корректность функций проверяется автоматическими unit-тестами.

## Возможности

- проверка одного паспорта целиком;
- поиск паспортных данных в тексте;
- поиск в текстовом UTF-8-файле;
- загрузка страницы по HTTP/HTTPS и поиск совпадений в её тексте;
- поддержка форматов `4509123456`, `4509 123456`, `4509-123456`, `45 09 123456`, `45-09-123456`;
- обработка сетевых ошибок, тайм-аутов и проблем чтения файла;
- автоматические тесты, в том числе с имитацией сетевых ответов, чтобы тесты не зависели от реального интернет-соединения.

Проверяется только синтаксическая форма: серия из четырёх цифр и номер из шести цифр. Программа не проверяет, существует ли такой паспорт на самом деле.

## Требования

- Python 3.10 или новее;
- пакет `requests` для загрузки веб-страниц.

Установите зависимость из каталога `laba_2`:

```bash
python -m pip install requests
```

## Запуск программы

```bash
python main.py
```

Программа предлагает меню:

1. проверить один паспорт;
2. найти паспортные данные в файле (по умолчанию `sample.txt`);
3. найти паспортные данные на веб-странице по URL;
4. выход.

## Запуск тестов

```bash
python -m pytest -v
```

Тесты проверяют корректные и некорректные паспорта, поиск совпадений, чтение файлов и поведение при ошибках. Сетевые запросы в unit-тестах имитируются, поэтому для запуска тестов интернет не требуется.

## Регулярное выражение

Серия состоит из четырёх цифр, номер — из шести. Цифры серии можно записать слитно или разделить пробелом либо дефисом; между серией и номером также допускается один пробел или дефис. При поиске применяются ограничения по соседним символам, чтобы не извлекать паспорт как часть более длинной последовательности цифр.
