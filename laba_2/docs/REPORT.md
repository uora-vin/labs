## 1. Цель работы

Изучить регулярные выражения в Python и технологию unit-тестирования,
а также применить их для проверки и поиска паспортных данных в строке,
локальном файле и тексте веб-страницы.

## 2. Постановка задачи

1. Составить регулярное выражение для серии из четырёх цифр и номера
   из шести цифр.
2. Реализовать функцию проверки одной строки и функцию поиска всех
   паспортных данных в тексте.
3. Предусмотреть чтение текста из UTF-8-файла и загрузку веб-страницы
   по URL.
4. Разработать консольное меню для проверки строки, поиска в файле
   и поиска на веб-странице.
5. Написать unit-тесты на pytest, не зависящие от реального
   интернет-соединения.
6. Подготовить отчёт и результаты тестирования.

## 3. Предметная область

Паспортные данные состоят из серии и номера. Серия содержит четыре
цифры, номер — шесть цифр. В учебной модели проверяется только
синтаксическая форма записи: программа не обращается к базам данных
и не проверяет, существует ли паспорт на самом деле.

Серия может быть записана слитно (`4509`) или двумя парами цифр
(`45 09`). Между серией и номером допускается один пробел или дефис.
Сами цифры остаются цифрами: буквы, лишние разделители и неверное
количество цифр считаются ошибкой.

### 3.1. Поддерживаемые форматы

| Формат | Пример | Пояснение |
|---|---|---|
| Слитная запись | `4509123456` | серия и номер без разделителей |
| Пробел | `4509 123456` | разделитель между серией и номером |
| Дефис | `4509-123456` | дефис между серией и номером |
| Серия из двух пар | `45 09 123456` | серия разделена пробелом |
| Серия с дефисом | `45-09-123456` | серия разделена дефисами |

## 4. Регулярное выражение

Основное выражение хранится в константе:

```python
_PASSPORT_BODY = r"\d{2}[ -]?\d{2}[ -]?\d{6}"
```

Для проверки всей строки используется `re.fullmatch`, а для поиска
в тексте — `re.finditer` с ограничениями по соседним символам:

```python
_PASSPORT_FULL = re.compile(_PASSPORT_BODY)
_PASSPORT_SEARCH = re.compile(rf"(?<!\d){_PASSPORT_BODY}(?!\d)")
```

### 4.1. Разбор выражения

| Элемент | Назначение |
|---|---|
| `\d{2}` | ровно две цифры |
| `[ -]?` | необязательный пробел или дефис |
| `\d{2}` | вторая пара цифр серии |
| `\d{6}` | ровно шесть цифр номера |
| `(?<!\d)` | слева не должно быть цифры |
| `(?!\d)` | справа не должно быть цифры |

Выражение допускает пять форматов из таблицы 3.1. Ограничения
`(?<!\d)` и `(?!\d)` не позволяют найти «паспорт» внутри более длинной
последовательности цифр, например в числе `0045091234567`.

При проверке используется `fullmatch`, поэтому строка должна целиком
соответствовать шаблону. Пробелы в начале и конце строки не удаляются:
пользовательский ввод очищается в меню отдельно.

## 5. Реализация

Программа состоит из одного модуля `main.py`. В нём определены
регулярные выражения, пользовательские функции и консольное меню.

### 5.1. Функции

| Функция | Назначение |
|---|---|
| `validate_passport(text)` | проверяет, что вся строка является паспортными данными |
| `find_passports(text)` | находит все паспорта в тексте в порядке появления |
| `read_from_file(filename)` | читает текст из файла в кодировке UTF-8 |
| `read_from_url(url)` | загружает страницу по HTTP/HTTPS и возвращает её текст |
| `show_results(text)` | выводит найденные значения или сообщение об их отсутствии |
| `main()` | запускает консольное меню |

Проверка строки:

```python
def validate_passport(text: str) -> bool:
    """Проверить, что вся строка является паспортными данными."""
    if not isinstance(text, str):
        return False
    return _PASSPORT_FULL.fullmatch(text) is not None
```

Поиск выполняется через `finditer`, поэтому возвращаются все совпадения
в порядке появления. Повторы не удаляются: если один и тот же паспорт
встречается в тексте дважды, он будет найден дважды.

```python
def find_passports(text: str) -> list[str]:
    """Найти все паспортные данные в тексте в порядке появления."""
    if not isinstance(text, str):
        return []
    return [match.group(0) for match in _PASSPORT_SEARCH.finditer(text)]
```

### 5.2. Консольное меню

Меню предлагает четыре действия:

1. проверить один паспорт;
2. найти паспортные данные в файле (по умолчанию `sample.txt`);
3. найти паспортные данные на веб-странице по URL;
4. выход.

Ввод пользователя обрабатывается в цикле `while True`. Ошибки
перехватываются внутри меню, поэтому программа не завершается
аварийно при неверном вводе.

### 5.3. Отличие от объектной модели

В лабораторной работе № 1 данные хранились в классах и сохранялись
в JSON и XML. В этой работе объект обработки — текст, поэтому вместо
CRUD и сериализации реализованы проверка строки, поиск совпадений
и чтение данных из файла или веб-страницы. Классы предметной области
здесь не требуются.

## 6. Обработка исключений

В программе используются встроенные исключения Python и понятные
сообщения об ошибках.

| Ситуация | Исключение | Обработка |
|---|---|---|
| URL не является полным HTTP(S)-адресом | `ValueError` | сообщение «Введите полный URL…» |
| ошибка сети или тайм-аут | `requests.RequestException` → `RuntimeError` | сообщение «Не удалось загрузить страницу…» |
| HTTP-статус 4xx/5xx | `requests.HTTPError` → `RuntimeError` | сообщение с текстом ошибки |
| файл не найден | `FileNotFoundError` | сообщение «Файл не найден…» |
| файл не в кодировке UTF-8 | `UnicodeError` | сообщение «Файл не является корректным UTF-8…» |
| другая ошибка чтения файла | `OSError` | сообщение «Не удалось прочитать файл…» |
| неверный пункт меню | — | сообщение и возврат в меню |
| Ctrl+C или конец ввода | `KeyboardInterrupt`, `EOFError` | корректный выход из программы |

В меню стоит один блок `try`, который перехватывает `ValueError`,
`OSError` и `RuntimeError`. Благодаря этому любая ошибка ввода или
загрузки выводится пользователю, а программа продолжает работу.

## 7. Работа с файлами и веб-страницами

### 7.1. Чтение файла

Функция `read_from_file` открывает файл в кодировке UTF-8 и возвращает
его содержимое целиком. Если файл отсутствует, выбрасывается
`FileNotFoundError` с понятным сообщением. Если файл повреждён или
сохранён в другой кодировке, выбрасывается `UnicodeError`.

### 7.2. Загрузка веб-страницы

Функция `read_from_url` проверяет, что передан полный HTTP(S)-адрес,
и выполняет запрос через библиотеку `requests`:

```python
response = requests.get(
    url,
    headers={"User-Agent": _USER_AGENT},
    timeout=10,
)
response.raise_for_status()
return response.text
```

Передаётся заголовок `User-Agent`, чтобы сервер не отклонил запрос как
запрос неизвестного клиента. Тайм-аут 10 секунд защищает программу
от бесконечного ожидания. Ошибки `requests` преобразуются в
`RuntimeError`, поэтому меню может показать одно понятное сообщение.

### 7.3. Демонстрационные данные

В файле `sample.txt` собраны корректные и некорректные записи.
Корректные примеры: `4509 123456`, `4510-654321`, `4511123456`,
`46 07 987654`. Ошибочные примеры: `4509 12345` (мало цифр в номере)
и `4509 1234567` (лишняя цифра). На этом файле программа находит
четыре паспорта.

## 10. Краткие ответы на вопросы к защите

1. **Регулярные выражения** — язык описания шаблонов поиска и проверки
   строк; позволяют находить, заменять и разбивать текст по правилу.
2. **Области применения** — проверка форматов (email, телефон, паспорт),
   поиск и замена в редакторах, разбор логов, валидация пользовательского
   ввода, обработка HTML.
3. **Синтаксис в Python** — шаблон задаётся строкой, специальные символы
   `\d`, `\w`, `\s`, квантификаторы `*`, `+`, `?`, `{n}`, группы `(...)`,
   классы `[...]`.
4. **`re.match()`** — ищет совпадение только в начале строки; возвращает
   объект `Match` или `None`.
5. **`re.search()`** — ищет первое совпадение в любом месте строки.
6. **`re.findall()`** — возвращает список всех совпадений; если в шаблоне
   есть группы, возвращает группы.
7. **`re.split()`** — разбивает строку по шаблону и возвращает список
   частей.
8. **`re.sub()`** — заменяет все совпадения на указанную строку или
   результат функции.
9. **`re.compile()`** — компилирует шаблон один раз; удобно использовать
   повторно и хранить в константе.
10. **HTTP-запрос в Python** — `requests.get(url)` отправляет GET-запрос;
    ответ содержит статус, заголовки и текст.
11. **Коды состояний** — 2xx успех, 3xx перенаправление, 4xx ошибка
    клиента, 5xx ошибка сервера.
12. **Ответ HTTP** — объект `Response`: `status_code`, `headers`, `text`,
    `json()`, `raise_for_status()`.
13. **Работа с файлами** — файл открывается через `open`, после работы
    закрывается; удобно использовать `with open(...) as file`.
14. **Чтение из файла** — `file.read()` читает весь текст, `readline()` —
    одну строку, `readlines()` — список строк.
15. **Запись в файл** — режимы `"w"` (перезапись), `"a"` (добавление),
    `"x"` (создание); кодировка задаётся параметром `encoding`.
16. **Отладка и тестирование** — отладчик, `print`, логи, модульные тесты,
    проверка граничных случаев.
17. **Виды тестов** — модульные, интеграционные, системные, приёмочные;
    по подходу — чёрный и белый ящик.
18. **Unit-тестирование** — проверка отдельных функций и модулей
    изолированно от остальной системы.
19. **Unit-тестирование в Python** — `unittest` или `pytest`; тесты
    запускаются автоматически и показывают, какой случай нарушен.
20. **Декораторы** — функции, которые принимают другую функцию и
    возвращают новую; используются для регистрации тестов, кэширования,
    логирования.
